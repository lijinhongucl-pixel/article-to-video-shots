# 镜头语言中英对照词表

写提示词时从这里取词，直接替换到自己的画面描述里。同一行左右两列意思对应，挑一边用即可。

## 景别

| 中文 | 英文 |
|---|---|
| 大远景 | extreme wide shot |
| 远景 | wide shot |
| 全景 | full shot |
| 中景 | medium shot |
| 特写 | close-up |
| 大特写 | extreme close-up |
| 俯视 | top-down view |
| 仰视 | low angle |
| 等距视角 | isometric view |
| 过肩镜头 | over-the-shoulder shot |

| 轻微手持感 | subtle handheld movement |

## 组合用法

一个典型的完整提示词是三段拼起来的，风格前缀加镜头语言加画面动作：

```
竖屏 9:16，电影级打光，干净的极简科技风 + 俯视视角，缓慢推进 + 桌面上多个窗口逐个关闭并向中心收拢成一把钥匙
```

vertical 9:16, cinematic lighting, clean minimal tech aesthetic + top-down view, slow push-in + multiple windows on a desk close one by one and converge into a single key
